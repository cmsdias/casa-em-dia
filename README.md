# Daily Casa

Aplicação doméstica partilhada (tarefas, rotinas, calendário da casa, compras, trabalhos e finanças) com contas próprias e quatro perfis de acesso. Corre como add-on do **Home Assistant**.

Este repositório contém apenas o add-on pronto a instalar e a demonstração. O desenvolvimento é feito num repositório privado.

## Instalar no Home Assistant

1. **Definições → Add-ons → Loja de add-ons → ⋮ → Repositórios**.
2. Acrescenta `https://github.com/cmsdias/daily-casa` e fecha.
3. Abre **Daily Casa**, instala e inicia. A aplicação aparece na barra lateral.

Os dados (tarefas, contas, palavras-passe, finanças e fotografias) ficam apenas no Home Assistant, em `/data`, e entram nas cópias de segurança do Home Assistant. Nunca são publicados aqui.
