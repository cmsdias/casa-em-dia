# Casa em Dia — Home Assistant OS

Repositório de aplicação do **Casa em Dia 1.0.0**, compatível com **Home Assistant Green** (aarch64).

## Instalar

1. Publica **apenas estes ficheiros** num repositório GitHub **público**, por exemplo `casa-em-dia-ha`.
2. No Home Assistant: **Definições → Aplicações → Instalar aplicação → ⋮ → Repositórios**.
3. Adiciona `https://github.com/TEU_UTILIZADOR/casa-em-dia-ha`.
4. Instala e inicia **Casa em Dia**.
5. Abre a aplicação, cria a conta admin e importa as tarefas de um ficheiro JSON pessoal **separado**.

As tarefas reais, utilizadores e palavras-passe **não fazem parte do repositório**. São guardados apenas no teu Home Assistant.

Lê o [guia completo](GUIA_PASSO_A_PASSO.md) e a [documentação da aplicação](casa_em_dia/DOCS.md).
